# Legal and compliance boundaries

This document is a product checklist, not legal advice.

## Code licensing

The upstream project is MIT licensed. Commercial use, modification,
distribution and sublicensing are permitted. Copies or substantial portions
must retain the upstream copyright notice and MIT permission notice. Keep the
repository `LICENSE` file and add a third-party notices file before commercial
distribution.

`penaltyblog` is also MIT licensed at the time it was selected. Pinning a
dependency does not replace dependency-license monitoring.

## Separate rights

Open-source code does not grant rights to bookmaker data, sports feeds,
trademarks, logos, API accounts or website automation. Each provider contract
must be approved for the intended use.

## Brazil product boundary

The MVP is an analytics subscription. It must not accept bets, set bookmaker
odds, hold customer balances or represent itself as an authorized betting
operator. Any expansion into those activities requires specialist advice and
regulatory analysis before implementation.

## Communications

- Never promise guaranteed wins, income or enrichment.
- Publish complete historical performance, methodology and material limits.
- Mark affiliate relationships clearly.
- Restrict the product to adults and include responsible-gambling guidance.
- Review all advertising and influencer arrangements before launch.

## Privacy and security

- Collect only necessary personal data.
- Create a lawful-basis and retention record for each data category.
- Keep API keys and credentials outside source control.
- Provide account deletion and data-subject request procedures.
- Perform a legal review covering LGPD, consumer law, advertising, provider
  contracts and the current SPA framework before public launch.
